# MundoCuadro Android

Proyecto Android listo para compilar con GitHub Actions.

- `targetSdk 36`
- ejecución offline del juego embebido
- controles táctiles y gamepad
- pantalla completa
- importación/exportación de partida

Abrí **Actions → Build MundoCuadro Android APK → Run workflow**. Al finalizar, descargá el artefacto `MundoCuadro_REBORN_Android_APK`.
